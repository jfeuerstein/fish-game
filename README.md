# Driftwood Cove

A cozy, lo-fi fishing game for an upright phone: a little island with a pier, a pond and a creek,
43 things to catch, a shop, errands, an arcade booth that takes pearls from the rarest fish, a
rowboat, chalk, a ukulele and a few islanders. It is drawn small and blown up, in a short palette. Add it to the Home Screen from Safari to play full screen.

```
npm install
npm run dev
```

See `CLAUDE.md` for how it is built and how the assets were made.
