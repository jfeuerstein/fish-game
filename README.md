# Driftwood Cove

A cozy fishing game for an upright phone: a little island with a pier, a pond and a creek, 36
things to catch, a shop, errands, chests to open with tokens from shiny fish, a rowboat, chalk,
a ukulele and a few islanders. Add it to the Home Screen from Safari to play full screen.

```
npm install
npm run dev
```

See `CLAUDE.md` for how it is built and how the assets were made.
